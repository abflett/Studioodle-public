# Studioodle 0.9.0 Beta

The first public beta: a free drawing and coloring studio with 364 stickers,
106 coloring pages, blank canvases, vector brushes and fills, stickers, and
PNG/SVG/PDF export.

- Windows 10/11 x64: download Studioodle_0.9.0_x64-setup.exe for installation.
- Standalone Windows ZIP: requires Microsoft WebView2 already installed.
- Browser edition: https://abflett.github.io/Studioodle-public/ (available after
  the website deployment finishes).
- The web ZIP is the reviewed static website used by the Pages workflow.
- SHA256SUMS accompanies the downloads for integrity checking.

No account is required. Pictures are saved locally in the app/browser where you
create them. Browser and Windows libraries are separate. Export important work
as a backup. Browser offline reload/install is not guaranteed yet.

This is an unsigned beta installer; Windows may show an unknown-publisher or
SmartScreen notice. It is not a Microsoft Store or Google Play release.

Finished pictures may be used personally or commercially. Underlying artwork,
reusable asset libraries and branding have separate terms. The installer, ZIP
and website include artwork terms, the application code license and third-party
notices. See the website footer or the package's legal directory.

Please report issues with the version, platform, reproduction steps and an
example export where useful: https://github.com/abflett/Studioodle-public/issues

Future fixes use 0.9.1, 0.9.2 and onward; feature/content updates can use 0.10.0.
Version 1.0.0 will mark the first stable public release.
