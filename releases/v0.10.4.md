# Studioodle 0.10.4 Beta - brighter social sharing

Shared links now feature a deep-blue preview card with gold lettering, mint accents and Studioodle flower artwork. Homepage and drawing-app links include complete large-image sharing metadata and image descriptions. The new image URL helps platforms fetch the refreshed artwork, though existing link previews may remain cached.

This release updates the website only. Windows and Android downloads remain at [0.10.1](https://github.com/abflett/Studioodle-public/releases/tag/v0.10.1).
