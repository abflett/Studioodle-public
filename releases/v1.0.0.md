Studioodle 1.0.0 is available for Windows and the web.

- Draw and color with brushes, fills, soft spray, 364 stickers and 106 bundled coloring pages.
- Save pictures locally without an account, and export PNG, SVG or PDF.
- Install the browser edition for offline use after its initial download.
- Read the privacy policy at https://studioodle.com/privacy/.

The Windows x64 NSIS installer includes the WebView2 offline installer. Publisher metadata is Flett. The installer and app are unsigned; Windows may show an unknown-publisher or SmartScreen warning. This release is prepared for an EXE/MSI Store submission but has not been certified by Microsoft. Silent installation uses `/S` (uppercase).

The Android download remains at 0.10.1; this release does not rebuild Android. Existing direct Windows installations and browser libraries retain their current storage identities. Export important pictures as backups; PNG/PDF exports do not restore editable drawings.
