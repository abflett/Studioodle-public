# Studioodle 0.10.0 Beta — offline web app and Android

- Install the browser app for offline drawing after its initial artwork download.
- Open **Install & updates** on the app home screen to check offline readiness and updates.
- Updates download separately, then wait until all Studioodle app tabs/windows close. Reopen to use the new version; drawings stay on the device.
- Download the signed **Android ARM64 APK** below for Android 7 or newer. Allow installation from your browser/file manager if prompted. No Google Play account or USB debugging is needed.

Android is a beta for manual installation, not a Google Play release. It is signed with Studioodle's permanent direct-download release key. Older private development-key builds cannot update in place: export important drawings before uninstalling the old tester app. Future APKs using this release key can update this build normally.

There is no new Windows build in this release. The [Windows 0.9.0 beta](https://github.com/abflett/Studioodle-public/releases/tag/v0.9.0) remains available and linked from the website.

Use [Studioodle online](https://studioodle.com/app/). On iPhone/iPad, open it in Safari and use Share → Add to Home Screen. Browser storage can be cleared or evicted; export important pictures as backups.

Verify downloads against the accompanying SHA256SUMS file. Finished pictures may be used personally or commercially. Bundled artwork and branding have separate terms; application code and third-party components retain their accompanying licenses.
