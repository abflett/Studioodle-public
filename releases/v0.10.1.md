# Studioodle 0.10.1 Beta

Updated Windows, Android and browser builds with a simpler web installation panel and gallery refinements.

- The browser app's home screen now has a status button beside Settings and Fullscreen. It shows download progress, offline readiness or a waiting update.
- Open the button for a full-screen panel with update checks, official downloads and illustrated iPhone/iPad, Android and computer installation instructions. A direct Install button appears when supported by the browser.
- Tap or click the enlarged gallery picture to edit it. The existing pencil button remains available.
- Website and app links now include a Studioodle social preview image, title and description.

## Downloads

- **Windows x64 installer:** `Studioodle_0.10.1_x64-setup.exe` (Windows 10/11). The unsigned beta may trigger SmartScreen or unknown-publisher prompts.
- **Windows standalone ZIP:** `Studioodle_0.10.1_windows-x64.zip`. Requires Microsoft WebView2.
- **Android ARM64 APK:** `Studioodle_0.10.1_android-arm64.apk` (Android 7+). Signed with the same release key as 0.10.0, allowing an in-place update. This is a manual-install beta, not a Google Play release.
- **Website ZIP:** reviewed static website and browser app used by GitHub Pages.

Use [Studioodle online](https://studioodle.com/app/). The offline app downloads updates separately and waits until all Studioodle app windows/tabs close before switching. If you still see the previous interface, finish drawing, close all app tabs/windows, reopen online and allow the update to download, then close/reopen again if an update is waiting.

Pictures stay on the device. Export important drawings as backups. Private development-key Android builds still need export/uninstall before switching to the public-release signing key; 0.10.0 release APK users do not need to uninstall.

Verify downloads against the accompanying SHA256SUMS file. Finished pictures may be used personally or commercially. Bundled artwork and branding have separate terms; application code and third-party components retain their accompanying licenses.
