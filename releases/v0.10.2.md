# Studioodle 0.10.2 Beta - web cache update fix

- Fixes older offline installs bringing back the floating **Install & updates** control after refresh.
- A fully downloaded web update becomes available on refresh, even while another Studioodle tab remains open. Existing drawing sessions are not automatically reloaded.
- Historical app assets remain available while older tabs need them, then their caches are retired. Saved drawings and preferences are retained.
- Offline downloads verify file contents against the reviewed build, preventing stale HTML from being stored as a newer version.
- The header has one globe button, with a spinner while downloading. Installation instructions, downloads and update checks stay inside its full-screen overlay.

Open [Studioodle online](https://studioodle.com/app/), allow the offline update to finish downloading, then refresh. This patch upgrades the original 0.10.0 offline worker without requiring every app tab to close.

This is a website-only release. The [Windows and Android 0.10.1 downloads](https://github.com/abflett/Studioodle-public/releases/tag/v0.10.1) remain current. No native build or signing-key change is included.
