# Studioodle 0.10.3 Beta - automatic web updates and download progress

- Online launches request the current app page, with a verified offline fallback. Older network HTML cannot downgrade the offline copy.
- The updater runs from browser startup, including while drawing. Completed updates apply automatically at the idle home screen after pending picture saves finish. Open drawings and panels are left uninterrupted.
- Download progress now includes a working animated spinner. Reduced-motion settings show a download icon and percentage instead of a frozen spinner.
- New offline downloads use an isolated cache generation so older workers cannot delete them mid-install. Cleanup removes only known retired builds, never newer in-progress downloads.
- Tests cover the original 0.10.0 worker, the 0.10.2 cleanup behavior, automatic home updates, a real painted document through an update, online freshness, offline reloads and both motion settings.

**Existing older tabs:** one ordinary reload or reopening the app is needed to receive this updater. Code already running in an older tab cannot gain the new automatic-update behavior retroactively. No developer tools, site-data clearing or cache resets are needed. Subsequent updates apply automatically when safe at home.

This release updates the website only. Windows and Android downloads remain at [0.10.1](https://github.com/abflett/Studioodle-public/releases/tag/v0.10.1).

Use [Studioodle online](https://studioodle.com/app/). Export important pictures as backups. Finished pictures may be used personally or commercially; artwork, branding, application code and third-party components retain their accompanying terms and licenses.
